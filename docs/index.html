Node Network

设备即节点
内容自由流动

每台运行史莱姆工坊的设备都是一个「节点」。电脑上的媒体库、书库与音乐，手机直接浏览播放；文件上传、远程管理，全部在局域网内完成。

  • 数据自持 — 没有云端中转，你的内容只属于你的设备
  • 多节点聚合 — 一个界面联合浏览多台设备的内容库
  • 流量可见 — 实时速率、请求统计与熔断保护，一目了然
  • 断点续传体验 — 视频 Range 流式播放，看到哪续到哪
